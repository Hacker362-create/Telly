How to start the server

  1. 1
    Make sure Node.js 18+ is installed.
    Download the LTS version from nodejs.org if needed.
  2. 2
    Open a terminal (or Command Prompt on Windows) and navigate to the folder that contains this file.
    Tip: in File Explorer, type cmd in the address bar and press Enter.
  3. 3
    Run the start script:
    macOS / Linux: ./start.sh
    Windows: start.bat
    The script installs dependencies, sets up the database, and starts the server on port 3000.
  4. 4
    Wait for the terminal to print:
    Telly backend listening on port 3000
    This page will detect it automatically and show the Open app button above.
App URL: http://localhost:3000  ·  Grafana: http://localhost:3001  ·  Prometheus: http://localhost:9090
